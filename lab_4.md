Завдання для четвертої лабораторної з циклу програмування полягає у побудові діаграми вороного на основі датасету з точками та виводі результаті у форматі зображення 960 x 540ю.
Для виконання роботи була вибрана мова програмування python і бібліотека для роботи з зображеннями pillow, оскільки вона є простою та надає увесь необхідний функціонал.

Код для лабораторної складається з 7 функцій:
- get_pixels_coords - читає координати з файлу і повертає їх у зручному форматі - список з кортежів розмірності 2
- transform_coords_to_image - переводить точки у іншу систему координат (з нижнього лівого кута у верхній лівий кут)
- find_connected_components - розбиває список точок у список зв'язних компонент з цих точок
- calculate_centroids - рахує координати центрів зв'язних компонент (центроїди)
- generate_voronoi_colors - створює палітру кольорів для діаграми вороного
- draw_voronoi_diagram - малює діаграму вороного
- main - виконує всі етапи для побудови діаграми вороного

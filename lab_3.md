Завдання для третьої лабораторної з циклу програмування полягає у пошуку опуклої оболонки для датасету з точками та виводі результаті у форматі зображення 960 x 540ю.
Для виконання роботи була вибрана мова програмування python і бібліотека для роботи з зображеннями pillow, оскільки вона є простою та надає увесь необхідний функціонал.

Код для лабораторної складається з 4 головних функцій:
- find_convex_hull - знаходить координати точок опуклої оболонки за алгоритмом Джарвіса
- get_pixels_coords - читає координати з файлу і повертає їх у зручному форматі - список з кортежів розмірності 2
- set_pixels - зафорбовує на зображенні пікселі з відповідними координатами у відповідний колір
- draw_hull_lines - з'єднує послідовні точки опуклої оболонки щоб результат було краще видно
